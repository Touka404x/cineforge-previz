# 数据与网络说明

## 数据保存位置

本工具在本机处理和保存项目数据：

- `user://settings.json`：界面和输出设置。
- 用户选择的 JSON 文件：场景、段落、关键帧、相机与环境数据。
- 用户选择的 PNG 和 MP4 文件：导出的静帧和视频。

项目文件不会主动写入账号密码、访问令牌、浏览器数据或设备唯一标识。

AI 预演的临时原文与计划会写在 Godot 的 `user://` 目录中，供本地 Python Agent 与应用之间传递；它们不会被自动上传。项目工程 JSON 不会写入模型 API 密钥。若需要调用兼容模型端点，密钥只能通过运行环境变量 `PREVIZ_LLM_API_KEY` 提供。

## 网络行为

场景编辑、播放、保存、导出，以及默认的 AI 预演规则均不需要联网。当前版本不提供项目上传、公开分享链接、远程素材、账号服务、遥测或应用内更新。

AI 预演的远程模型调用是可选能力，默认关闭。只有使用者同时设置 `PREVIZ_LLM_MODE=openai-compatible`、`PREVIZ_LLM_BASE_URL` 和 `PREVIZ_LLM_MODEL` 后，本地 Agent 才会向该端点发送小说原文或用户明确提供的预览图以完成规划/复核。端点可以是本机模型服务，也可以是使用者自行选择的远程服务；失败不会阻塞手工预演，且不会触发重试下载或后台联网。

MCP 服务使用标准输入/输出与宿主进程通信，默认也不联网。它只暴露模型目录检索、小说规划和计划验证，不提供命令执行、通用文件读写或工程自动写入工具。

如果需要把预演交给其他人查看，请先导出 PNG 或 MP4，再通过你选择的平台进行分享。

## 视频导出

导出 MP4 时，应用会在本机执行两个步骤：

1. Godot 渲染当前段落并生成临时 AVI 文件。
2. 本地 `ffmpeg.exe` 将 AVI 编码为 H.264 MP4；成功后删除临时文件。

这些步骤只处理本地文件路径，不会把项目或视频上传到网络。
