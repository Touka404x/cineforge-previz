# 数据与网络说明

## 数据保存位置

本工具在本机处理和保存项目数据：

- `user://settings.json`：界面和输出设置。
- 用户选择的 JSON 文件：场景、段落、关键帧、相机与环境数据。
- 用户选择的 PNG 和 MP4 文件：导出的静帧和视频。

项目文件不会主动写入账号密码、访问令牌、浏览器数据或设备唯一标识。

## 网络行为

当前版本不提供项目上传、公开分享链接、远程素材、账号服务、遥测或应用内更新。应用不需要访问服务端即可完成场景编辑、播放、保存和导出。

如果需要把预演交给其他人查看，请先导出 PNG 或 MP4，再通过你选择的平台进行分享。

## 视频导出

导出 MP4 时，应用会在本机执行两个步骤：

1. Godot 渲染当前段落并生成临时 AVI 文件。
2. 本地 `ffmpeg.exe` 将 AVI 编码为 H.264 MP4；成功后删除临时文件。

这些步骤只处理本地文件路径，不会把项目或视频上传到网络。
